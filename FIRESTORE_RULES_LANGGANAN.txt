===========================================================================
SUNTINGAN 1 — izinkan pengguna memasang penanda pratinjau (SEKALI)
===========================================================================

Cari blok:            match /langganan/{uid} {

Di dalamnya sudah ada `allow read`, `allow create`, dan baris terakhir:

      allow update, delete: if request.auth != null
                            && request.auth.uid == 'EOrakx0QnSVgsi6BECSOXvUM9kG3';

SISIPKAN blok berikut TEPAT SEBELUM baris `allow update, delete` itu:

      // Satu-satunya update yang boleh dilakukan pengguna biasa: memasang
      // field "pratinjau" SEKALI, dengan waktu server.
      //
      // Empat syarat, keempatnya perlu:
      //  - fieldnya BELUM ada        -> pratinjau tidak bisa diulang
      //  - nilainya request.time     -> jam perangkat tidak bisa dipakai
      //  - hanya "pratinjau" berubah -> bayarSampai tidak bisa disisipkan
      //                                 dalam permintaan yang sama
      // Hilangkan salah satunya dan 24 jam itu berhenti berarti apa-apa.
      allow update: if request.auth != null
                    && request.auth.uid == uid
                    && !('pratinjau' in resource.data)
                    && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['pratinjau'])
                    && request.resource.data.pratinjau == request.time;

`allow` yang berkali-kali di-OR-kan, jadi baris pemilik di bawahnya tetap
berlaku penuh dan tidak perlu diubah.

===========================================================================
SUNTINGAN 2 — jendela otomatis: dari 30 hari "mulai" jadi 24 jam "pratinjau"
===========================================================================

Cari fungsi di bagian bawah berkas:   function langgananAktif(uid) {

Di dalamnya ada klausa seperti ini (angka harinya mungkin 30):

        || (
          'mulai' in langgananData(uid)
          && langgananData(uid).mulai + duration.value(30, 'd') > request.time
        )

GANTI seluruh klausa itu dengan:

        // Dihitung dari "pratinjau", BUKAN dari "mulai". Bedanya menentukan
        // segalanya: "mulai" ditulis pada login pertama SIAPA PUN, jadi
        // memakainya berarti setiap orang yang login otomatis dapat 24 jam
        // dan kuota event 30 hari di /akses jadi tidak ada gunanya.
        // "pratinjau" hanya ada kalau orangnya menekan tombol Preview.
        || (
          'pratinjau' in langgananData(uid)
          && langgananData(uid).pratinjau + duration.value(24, 'h') > request.time
        )

Klausa `bayarSampai` di bawahnya JANGAN disentuh — itu yang menjaga akses
orang yang sudah membayar atau disetujui.

===========================================================================
SESUDAH PUBLISH — CARA MEMASTIKAN BERHASIL
===========================================================================

1. Buka https://jaditrader.co.id/#/template dengan akun Google KEDUA
   (bukan akun pemilik — pemilik selalu dilewatkan tanpa perlu pratinjau).
2. Klik "Preview tools · 1 hari" -> Mulai pratinjau 24 jam.
3. Yang harus muncul: masuk ke Dashboard, dengan pita BIRU di atas
   berbunyi "Mode pratinjau — sisa 23 jam …".
4. Kalau muncul pesan merah "permission-denied", berarti suntingannya
   belum tersimpan — periksa lagi Suntingan 1.

Uji kedua, yang membuktikan gerbangnya tidak bocor: keluar, lalu login
dengan akun ketiga TANPA menekan tombol Preview. Ia harus dilempar ke
/akses, bukan masuk. Kalau ia masuk, berarti Suntingan 2 belum terpasang
dan jendela masih dihitung dari "mulai".

===========================================================================
CATATAN
===========================================================================

• Akun yang sudah punya bayarSampai aktif tidak terpengaruh sama sekali
  oleh kedua suntingan ini.

• Akun yang sudah pernah login tapi belum pernah menekan Preview akan
  terhitung 'habis' dan diarahkan ke /akses. Itu memang yang diinginkan.

• Orang bisa membuat akun Google baru untuk mendapat 24 jam lagi. Tidak
  bisa ditutup di sistem mana pun yang memakai login gratis — tapi
  imbalannya sehari, bukan sebulan.
