Panduan alat

  • Cara Menghubungkan MetaTrader 5 ke Jurnal Trading Otomatis

    Enam langkah memasang EA JadiTraderSync di MT5 supaya setiap transaksi masuk ke jurnal sendiri — tanpa menyalin satu baris pun dari riwayat.

  • Cara Membuat API Key Binance yang Aman untuk Screener dan Chart

    Satu centang yang tidak boleh diaktifkan, kenapa API key tidak pernah masuk ke peramban, dan apa bedanya dengan App Token.

  • Kenapa Data Binance Tidak Masuk di Indonesia, dan Cara Mengatasinya

    Chart kosong dan screener yang tidak mengisi biasanya bukan bug aplikasi — melainkan blokir di jaringan ISP-mu.

  • Akun Sen di MT5 Bisa Membuat Jurnalmu Terlihat 100× Lebih Untung

    Kenapa akun cent perlu diperlakukan berbeda, dan bagaimana saldo, swap, komisi, serta winrate gabungan dihitung.

  • Cara Memasang Indikator Pine di TradingView (dan Satu Sebab Gagal yang Paling Sering)

    Menempel kode Pine, menyimpannya ke favorit, dan kenapa indikator v6 tidak mau dikompilasi di layout lama.
